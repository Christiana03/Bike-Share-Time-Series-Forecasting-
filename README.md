# Bike-Share Time Series Forcasting
Applied time series forecasting techniques to identify demand patterns, generate forecasts and evaluate accuracy using MAD, MAPE and MSE

## Project Overview
A time series forecasting project analysing bike-sharing demand to identify trends and patterns and generate forecasts to support demand planning.

## Tools & Techniques
- Microsoft Excel
- Time Series Analysis
- Forecasting
- Forecast Accuracy Evaluation

## Project Objectives
- Explore historical bike-sharing demand.
- Identify trends and patterns in usage.
- Apply time series forecasting techniques.
- Evaluate forecast performance using MAD, MAPE and MSE.

## Project Deliverables
- Excel forecasting workbook.
- Forecast analysis and evaluation.
- Project report and key findings.

## Data Availability
Refer to the accompanying project files for the analysis and findings. Dataset availability is subject to the original data-sharing permissions.
